Quick start

Build and send your tweaks

Add Lua, review slots, then copy commands to BAR chat · Expand guide
  1. 01

    Load a library Optional

    On the hosted site, choose files from the published library; your enable/disable choices are saved in this browser. For local library editing, run node server.js, add .lua files to tweaks/defs or tweaks/units, then pick them in the library tab.

  2. 02

    Add your Lua

    Use tweakdefs for runnable Lua (with UnitDefs in scope), or tweakunits for a Lua unit table. Library files work too.

  3. 03

    Check your slots

    Your tweaks are minified and encoded for you. A slot turns red if its command is over the character limit.

  4. 04

    Pack when ready

    Auto-pack combines snippets in source order into as few slots as possible without exceeding the limit. Unterminated literals/comments or unsafe tweakunits tables stop the pack without partial output.

  5. 05

    Copy & send

    Copy a slot or all commands, then paste each command into BAR lobby chat.

  6. 06

    Reset whenever

    Use Copy reset all and paste the commands into chat to clear all tweakdefs and tweakunits slots.
