Teiserver caps messages at 16,384 chars incl. command.

How to use

  1. Server (optional): run node server.js, open http://localhost:8080, drop .lua files into tweaks/defs / tweaks/units and tick them in the server library tab — enabled files flow into the packer automatically.
  2. Paste Lua below (tweakdefs = runnable Lua code with UnitDefs in scope, tweakunits = Lua table like { armpw = { metalcost = 10, }, }).
  3. Each slot is minified, then base64-encoded. Slots that exceed the limit turn red.
  4. Use Auto-pack to combine small snippets into the fewest slots possible without exceeding the limit.
  5. Press Copy per slot, or Copy all, become lobby boss (!boss), then paste each line into lobby chat.
  6. To clear tweaks lobby-side, Copy reset and paste: each !bset <slot> 0 line resets that slot to empty.
